# SIGMA13-Frecuencia-Pura
Sigma-13 es un marco de trabajo abierto que traduce reglas aritméticas, proporciones áureas (phi) y relaciones frecuenciales en estructuras musicales completas. El proyecto establece un método replicable para organizar álbumes, progresiones de tempo (BPM) y afinaciones específicas en hercios, separando explícitamente el rigor de la capa creativa
